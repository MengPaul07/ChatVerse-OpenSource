# Built-in stage assets

These assets are bundled fallbacks for the starter-world stage view. A user's
uploaded or generated visual asset always takes precedence over these files.

- `red-chamber-haitang`: original spring poetry-gathering background and portraits.
- `archive-room`: video-production archive-room background and portraits, plus two role-matched additions.
- `sakura-hill-school-festival`: video-production academy background and portraits, plus two role-matched additions.
- `solvay-conference-1927`: original 1927 conference background and period portraits.

The five-elements mountain assets already used by the product are intentionally
left unchanged.
